# NCAA Quality Assurance & Internal Audit System

A comprehensive internal audit management platform for the **Nigerian Civil Aviation Authority (NCAA)**, built with Laravel 12, Livewire 3, Flux UI, and AI-powered reporting via the Gemini API.

---

## Features

- **Executive Dashboard** — KPI cards, Chart.js charts, heat map, overdue CAPs table
- **Audit Registry** — Full audit lifecycle from planning → field work → review → approval → certificate
- **NCR & CAP Tracking** — Non-Conformity Reports with Corrective Action Plans and due date monitoring
- **AI-Powered Reporting** — Executive reports generated by Gemini (falls back to realistic demo AI)
- **Compliance Certificates** — PDF issuance with QR-code verification
- **Role-Based Access** — 7 roles covering every stage of the audit workflow

## Setup

### 1. Clone & install dependencies

```bash
git clone <repo-url> qa-ncaa
cd qa-ncaa
composer install
npm install
```

### 2. Configure environment

```bash
cp .env.example .env
php artisan key:generate
```

Edit `.env` and set your database connection (defaults to SQLite — no changes needed for local dev):

```env
DB_CONNECTION=sqlite
# DB_DATABASE=/absolute/path/to/database.sqlite  # auto-created if omitted
```

### 3. AI Report (optional)

To enable live Gemini AI report generation, add your API key:

```env
GEMINI_API_KEY=your_key_here
```

If `GEMINI_API_KEY` is empty or absent, the system automatically falls back to a realistic **FakeAiService** — no errors, fully functional for demos.

### 4. Seed the database

```bash
php artisan migrate:fresh --seed
```

This creates all demo users, 6 audit processes across 3 directorates, 12 audits, 9 NCRs (2 overdue), and 3 compliance certificates.

### 5. Build frontend assets

```bash
npm run build
```

For development with hot-reload:

```bash
npm run dev
# or the full stack:
composer run dev
```

### 6. Start the application

```bash
php artisan serve
```

Visit [http://localhost:8000](http://localhost:8000)

## Scheduled Tasks

The system uses Laravel's task scheduler. For production, add this cron entry:

```cron
* * * * * cd /path-to-project && php artisan schedule:run >> /dev/null 2>&1
```

For local development, run the scheduler in the foreground:

```bash
php artisan schedule:work
```

## 5-Minute Demo Script

### 1. Executive Overview (2 min)
1. Log in as **System Admin** (`admin@ncaa.gov.ng` / `password`)
2. You land on the **Executive Dashboard**:
   - Review KPI cards (audits this month, in progress, certificates, open NCRs, overdue CAPs)
   - Note the **Directorate NCR Heat** panel — DOLG is red (3+ NCRs), click it to filter the NCR list
   - Check the **Overdue CAPs** table — 2 items require immediate attention
3. Click **"Generate AI Report"** → select "Last 30 Days" → click **Generate Report**
   - View the AI-generated executive summary in the modal
   - Click **Download PDF** to save the report

### 2. Audit Workflow (2 min)
4. Navigate to **Audits** → view the full registry with status badges
5. Log out → log in as **Field Auditor** (`auditor@ncaa.gov.ng`)
6. Open an in-progress audit → complete the AI-generated checklist → submit findings
7. Log out → log in as **Reviewer** (`reviewer@ncaa.gov.ng`) → review and approve the submission

### 3. Approval & Certificate (1 min)
8. Log in as **Director** (`director@ncaa.gov.ng`) → approve the audit
9. Issue a compliance certificate — download the signed PDF
10. Visit the public verification URL printed on the certificate to confirm authenticity
